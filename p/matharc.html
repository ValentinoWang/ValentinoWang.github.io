01概况

背景
让大模型「再想想」，常常得到看似完整、其实漏了一步的证明。求解器超时、结果未知，写进报告也容易被当成结论。
目标
局部进展不冒充全局证明：每条结论标明范围和证据等级，并能被另一条思路独立重建。
我负责
独立设计和开发。用它做的 ES(7)=33 研究，论文作者是我；档案里写明了 AI 参与探索、代码和编辑。

02方案与取舍

冻结命题 → 分几条思路 → 拆成原子主张和证明义务 → 调精确计算、SAT 求解或形式化工具 → 每一步都有人试着推翻 → 失败沿依赖图回传 → 独立重建。

选了主张依赖图：模型只提候选，靠检查和独立重建升级

没选让模型自评「证完了」

模型会很自信地跳步。代价是每条主张都要写证明义务、配证据。

选了上亿条枚举结果只记清单、大小和哈希

没选全部放进 Git

仓库会拖不动。代价是复现时要另外取回大文件。

03难点

现象

局部计算结果容易被写成「证明了」。

原因

超时和部分结果在报告里看起来和证明差不多。

解法

局部定理必须附可重放证据；全局判定单独列为未完成；档案首页写明「不声称证明 ES(7)=33」。

04结果

公开研究档案归档了一批带证书的局部结构结果和一份 arXiv 格式手稿（数字见主页 03 学术）。原问题仍未解决。
